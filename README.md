## 机房怎么选：DC3 的流量缩水规则

Basic 的机房以美国为主：洛杉矶的 DC8 ZNET、DC2、DC3 CN2，加上弗里蒙特、新泽西、纽约，海外还有荷兰阿姆斯特丹和加拿大温哥华。

线路层面先说清楚一件事：Basic 里带"CN2"字样的只有洛杉矶 DC3，而且是普通 CN2（GT 级别）。搬瓦工真正的 CN2 GIA 中国优化线路，只在 E-Commerce 和 Ultra 系列的指定机房里。如果你是冲着 CN2 两个字选的 Basic，拿到手发现速度和预期有落差，问题就出在这里。

还有个更容易踩的坑：

> **选 DC3 CN2 机房，月流量按套餐标称的三分之一计算。** 1GB 套餐标 1TB/月，切到 DC3 实际只有约 333GB；2GB 档的 2TB 也变成约 666GB。DC3 恰恰是 Basic 里最容易被新手选中的机房，因为名字里带 CN2。

所以实际建议是：要大流量就选 DC8 ZNET 或弗里蒙特这类机房；既想要 CN2 又不想流量缩水，别在 Basic 里纠结，直接往下看 E-Commerce。

## Basic 适合谁，不适合谁

Basic 适合预算卡在每年 50 美元以内、对国内访问速度没有硬需求的用户。典型场景：学 Linux、搭开发测试环境、跑个人博客和小型企业官网、挂一些流量不大的海外业务。1GB 内存跑这些够用，2GB 档（$99.99/年）能覆盖得更稳一些。

反过来，这几种情况别选 Basic：

- **跨境电商、面向国内用户的网站**：晚高峰速度一般，该看 E-Commerce 或 Ultra。
- **大流量、高带宽需求**：Basic 封顶 6TB/月、1Gbps；E-Commerce 高配档能到 10Gbps、12TB 月流量。
- **收费业务对在线率敏感**：99.99% 的承诺只有 SLA 系列才有。
